# Nordic Nest – Custom WooCommerce Theme

A minimal, custom WordPress + WooCommerce theme designed for a modern Home & Living store.  
Built from scratch with a clean Scandinavian aesthetic.

---

## Overview

**Nordic Nest** is a fully custom theme focused on simplicity, soft colors, and a calm shopping experience.  
It was developed as a portfolio project to demonstrate custom WordPress theme development and WooCommerce integration.

---

## Features

- Custom header with centered logo, search, and hanging cart badge
- Hero section editable via WordPress Customizer
- Responsive product grid
- Custom single product layout
- Styled Cart & Checkout (WooCommerce Blocks compatible)
- Mobile-first bottom navigation
- Clean typography (DM Sans + Cormorant Garamond)
- Soft Nordic color palette
- Fully responsive (desktop & mobile)

## Installation

1. Download or clone this repository
2. Copy the `nordic-nest` folder into `/wp-content/themes/`
3. Activate the theme from **Appearance → Themes**
4. Install and activate **WooCommerce**
5. Set up pages (Shop, Cart, Checkout, My Account) via WooCommerce wizard
6. Go to **Appearance → Customize** to set:
   - Logo
   - Hero image, title, description, and button text
   - Footer texts
